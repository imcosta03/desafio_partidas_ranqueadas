# Calculadora de Partidas Rankeadas

## Descrição
Este projeto faz parte da **Formação de Lógica de Programação** da DIO e tem como objetivo praticar:
- Variáveis
- Operadores
- Laços de repetição
- Estruturas de decisão
- Funções

O desafio consiste em criar uma função que recebe como parâmetro a quantidade de **vitórias** e **derrotas** de um jogador.  
A partir disso, o programa calcula o **saldo de vitórias** e determina o **nível** do jogador conforme a quantidade de vitórias.

---

## Regras de Classificação

- Se vitórias **< 10** → **Ferro**
- Se vitórias **entre 11 e 20** → **Bronze**
- Se vitórias **entre 21 e 50** → **Prata**
- Se vitórias **entre 51 e 80** → **Ouro**
- Se vitórias **entre 81 e 90** → **Diamante**
- Se vitórias **entre 91 e 100** → **Lendário**
- Se vitórias **>= 101** → **Imortal**

---

## Como Executar
- Salve o código em um arquivo chamado prog.js.
- Abra o terminal na pasta do arquivo.
- Execute: node prog.js
- Digite as vitórias e derrotas quando solicitado.
- Veja o resultado no console.

## Objetivo do Projeto
Este desafio ajuda a consolidar os conceitos fundamentais de lógica de programação:
- Uso de funções para organizar o código.
- Aplicação de estruturas condicionais para tomada de decisão.
- Utilização de variáveis e operadores para cálculos.
- Entrada e saída de dados no console.
